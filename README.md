# 🧙 Machine à invocation

Un petit projet interactif permettant d'invoquer des créatures fantastiques à partir d'un formulaire.

## ✨ Fonctionnalités

- Saisie du prénom et du nom de l'utilisateur.
- Sélection d'une créature dans une liste déroulante.
- Invocation aléatoire d'une créature.
- Affichage de l'image et de la description de la créature invoquée.
- Possibilité de lancer une nouvelle invocation.

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript (ES6+)

## 🎯 Objectif du projet

Mettre en pratique la manipulation du DOM, les événements JavaScript, les tableaux d'objets, les fonctions et les modules ES6.
